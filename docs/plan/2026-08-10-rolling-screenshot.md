# Fewer 滚动截图实施计划

## 摘要

- 计划文档保存为 `docs/plan/2026-08-10-rolling-screenshot.md`；目录不存在时创建。
- 在现有区域截图工具条增加“滚动截图”菜单，提供“手动滚动”和“自动滚动”两种模式。
- 首版仅支持同一显示器、固定宽度选区、单个容器向下滚动；完成后复用现有截图结果窗口及复制、保存、标注、贴图流程。
- 现有核心测试基线为 118 项全部通过；当前 `rollingCaptureEnabled` 和 `StitchEngine` 只是未接入 UI 的原型。

## 实现方案

### 捕获流程与界面

- 扩展区域选择回调，使“普通截图”“手动滚动”“自动滚动”共享同一选区；`rollingCaptureEnabled == false` 时隐藏滚动入口，不新增独立快捷键。
- 新增单一滚动截图状态机：`preparing → capturing → paused → finishing → completed/cancelled`，确保任意时刻只存在一个截图会话。
- 开始会话前记录目标应用，关闭选择遮罩后恢复目标应用；显示不激活应用的悬浮 HUD，提供进度、暂停/继续、完成、取消，并注册会话期间有效的 Esc 取消键。
- 滚动帧使用 macOS 14 的 ScreenCaptureKit 单次区域捕获，固定像素尺寸、关闭鼠标指针并排除 Fewer 自身窗口；现有区域、窗口、全屏截图后端保持不变。
- 手动模式轮询选区并在连续两帧稳定后接收新帧；提示用户每次向下滚动不超过选区高度 80%，滚动后短暂停顿。
- 自动模式每轮只发送一次约为选区高度 60% 的向下滚动，等待画面稳定并成功拼接后才进入下一轮，连续两次无新增内容视为到底。

### 自动滚动与权限

- 复用已具备辅助功能权限的 `FewerShortcutHelper` 注入像素单位滚动事件；主应用通过带会话 UUID 的分布式通知发送选区中心、滚动距离和命令，并等待 Helper 回执。
- Helper 校验辅助功能授权、会话标识、向下方向和单次距离上限；滚动命令与 Finder 快捷键处理保持独立，不能因 Finder 快捷键开关关闭而禁用滚动截图。
- Helper 未运行时按需启动并等待最多 2 秒；未授权、回执超时、目标无响应时暂停，明确提供“请求权限”“改用手动”“完成已有部分”“取消”，不得静默降级。
- 设置页补充滚动截图开关、自动模式辅助功能状态和用途说明；不增加新 entitlement，不迁移或清空现有截图设置。

### 拼接引擎

- 将现有逐行完全相等原型升级为增量垂直配准：降采样灰度特征、粗到细搜索正向位移、剔除异常行后计算 `0...1` 置信度；默认最低置信度为 `0.90`。
- 新增 `StitchConfiguration`、`StitchMatch`、`StitchFailure`，并将 `StitchEngine` 对外接口调整为“分析相邻帧”和“合成长图”；现有精确行哈希方法降为内部实现或删除。
- 检测相邻帧中同位置保持稳定的顶部/底部连续区域，每侧最多占选区高度 30%，连续两次确认后视为固定栏；最终仅保留首帧顶部固定栏和末帧底部固定栏各一次。
- 仅接受正向位移和宽度、缩放一致的帧；反向滚动、横向位移、布局变化或置信度不足时不写入画布，暂停并说明原因。
- 使用增量片段合成，避免每帧重建整张长图；限制输出为最多 64,000,000 像素、32,000 像素高度或 120 个有效帧。达到限制时暂停并允许输出当前有效部分。
- 所有完成路径编码为 PNG 并交给现有结果窗口；取消路径清理任务、HUD、临时热键和 Helper 会话，不产生文件或部分结果。

## 接口与失败行为

- `CaptureOverlayDelegate` 增加滚动截图启动回调，参数包含选区和 `RollingCaptureMode.manual/automatic`。
- `ScreenshotService` 持有滚动会话控制器，并统一处理开始、模式切换、完成、取消和清理。
- `FewerCore` 提供可单元测试的拼接配置、匹配结果、失败原因及 Helper 命令载荷；AppKit 窗口、ScreenCaptureKit 和滚动事件注入留在平台层。
- 失败原因至少区分：权限不可用、目标应用退出、捕获失败、目标未滚动、方向不支持、尺寸变化、匹配不可靠、输出超限。
- 记录会话模式、目标 bundle ID、帧接受/拒绝、位移、置信度、固定栏尺寸、停止原因和输出尺寸；不记录截图图像或页面内容。

## 测试与验收

- 核心单测覆盖：正常向下位移、重复帧、超过 240 行重叠、轻微像素噪声、固定顶部/底部、反向滚动、宽度变化、低置信度、输出限制及设置旧数据解码。
- 状态机测试覆盖：手动完成、自动到底、暂停后继续、自动显式切手动、权限失败、Helper 超时、捕获失败和取消清理。
- 真实路径验证：
  - Safari/原生 `NSScrollView` 分别完成手动与自动长截图。
  - 含吸顶导航和固定底栏的页面最终各只保留一次固定区域。
  - HUD、选区边框和鼠标指针不进入成图。
  - 未授权和不响应目标不会自动降级或生成错拼图片。
  - 长图可正常进入标注窗口并完成复制、保存和贴图。
- 回归验证现有区域、窗口、全屏截图及快捷键行为不变。
- 执行核心测试、无签名完整应用构建，并用签名运行版本完成屏幕录制与辅助功能权限下的真实滚动验收；连续滚动事件必须证明“一次捕获循环只前进一步”。
- 保留当前脏工作区和用户已有截图实现，不恢复已删除的 `docs/superpowers` 文档，不改动无关文件。
