# T008: 网络模块与默认路由统计

## 元信息

- 优先级：P0
- 状态：REVIEW
- 推荐执行器：implementer
- 依赖：T003

## Goal

修复上传/下载数值：只统计当前默认路由接口，VPN 成为默认路由时统计 VPN；提供网络模块的真实状态项与弹窗数据，Wi-Fi 明细按需请求位置权限。

## 范围

- `FewerApp/Services/SystemMetricsService.swift`
- `FewerApp/App/FewerApp.swift`
- `FewerApp/Info.plist`
- `project.yml`
- 确有必要的新 FewerApp 网络服务/视图文件。

## 要求

- 解析 IPv4/IPv6 默认路由接口，避免累计 loopback、bridge、非默认虚拟接口；接口改变、计数倒退或首次采样时只建立基线，不能显示伪造峰值。
- 默认接口信息、IPv4/IPv6 本地地址、累计收发、当前速率和连接状态接入 `SystemMetricsService`；状态项和通用网络弹窗使用真实值。
- VPN/utun 成为默认路由时明确选中它；VPN 非默认路由时仍统计物理默认接口。
- Wi-Fi SSID/BSSID/信号仅用户展开网络详情后请求定位权限；拒绝或不支持时显示“不可用”，不能影响速率。
- 保留公网 IP 手动刷新；不新增周期性外网请求。

## 排除项

- 不实现 CPU/GPU/内存/磁盘采样，不实现网络通知、桌面小组件或进程级网络归因。
- 不修改 Core、ShortcutHelper、.agent 协调状态。

## 验证

- Fewer Debug build 与相关单元测试。
- 用可注入/纯函数测试接口选择、首次采样、切换、倒退和速率计算；实机验证作为 T012 验收项。

## Completion Report

- 默认路由优先 IPv4、回退 IPv6，只统计该接口的 AF_LINK 计数。
- 接口切换、断连、首次采样和计数倒退均重新建立基线并返回零速率。
- 弹窗接入默认接口、IP、累计量、速率和按需 Wi-Fi 明细；定位拒绝/无 Wi-Fi 显示不可用。
- 验证：`xcodegen generate`、完整 `./script/verify.sh` 和 Debug build passed（258 Core tests）。
