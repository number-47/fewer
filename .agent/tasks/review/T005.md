## 要求

- 参考 `/tmp/codex-stats-v3.0.11/Modules/GPU/{reader.swift,bridge.h}`；如移植实质代码，完整保留 Stats MIT 许可文本。
- 从 IOKit `IOAccelerator`/`PerformanceStatistics` 读取每个 GPU 的使用率、Render、Tiler、型号、类型、核心数；识别 Intel、AMD、Apple Silicon，设备 ID 稳定且可由偏好选择。
- Apple Silicon 使用 IOReport 获取 DCP FPS 与 ANE；首样本/无通道/私有接口失败为 nil/“不可用”，绝不写 0。
- 添加 `libIOReport.tbd` 和统一桥接声明；失败路径不能影响启动、签名、Hardened Runtime 或无 GPU 硬件环境。
- GPU 状态项与弹窗接入真实数据，显示自动/已选设备、类型、模型、核心、总/Render/Tiler、FPS、ANE、历史；支持现有组件偏好。
- 不修改 Core、ShortcutHelper、网络/CPU采样和 .agent 协调文件。
