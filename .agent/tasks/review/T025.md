# T025: R5 — 设置窗口响应与后台状态刷新

## 元信息

- ID：T025
- 优先级：P1
- 状态：REVIEW
- 推荐执行器：implementer
- 依赖：T013, T020, T022

## Goal

消除设置窗口打开、切页、停留和拖动控件时的主线程阻塞；后台刷新状态有生命周期、有缓存，不持续启动进程或同步读写文件。

## Rationale

Overview 每秒在 MainActor 调用 `ExtensionStatusService.finderExtensionStatus()`，内部启动 `/usr/bin/pluginkit` 并 `waitUntilExit()`。`SettingsViewModel` 和 `InputEnhancementViewModel` 在 MainActor 同步读写 Store；所有 slider binding 每次变化都会写盘并发 DNC；shared InputEnhancementViewModel 的一秒 timer 在离开页面后仍长期运行。

## Scope

- `RootSettingsView`、`OverviewView`、`InputEnhancementSettingsView`
- `SettingsViewModel`、`InputEnhancementViewModel`
- `ExtensionStatusService`、`PermissionService`
- 其余设置 pane 的同步 I/O/Process 审计
- UI Tests 和轻量性能测试/日志

## Relevant files

- `OverviewView.task`
- `ExtensionStatusService.finderExtensionStatus`
- `SettingsViewModel.init/saveSettings/reloadTemplates`
- `InputEnhancementViewModel.init/refreshStatus/save`
- `InputEnhancementSettingsView.binding/slider`

## Requirements

1. 先 profile 设置首次打开、Overview 停留 5 秒、切换每个 pane、连续拖动三个 slider。
2. `pluginkit` 和其他 `Process.waitUntilExit` 移到后台，带超时、缓存和单飞；按窗口激活/手动刷新触发，不每秒启动进程。
3. Store/template 读取在后台完成，MainActor 只发布状态；页面可先显示加载态，不阻塞首帧。
4. Toggle/离散 Picker 可立即持久化；slider/text 连续编辑使用短 debounce，并在编辑结束、切页和窗口关闭前 flush 最终值。
5. 合并 DNC 通知，避免滑动一次产生大量跨进程 reload；最终设置必须不丢失。
6. InputEnhancement 状态轮询只在相关页面可见时启动，离开后停止；Helper 心跳使用缓存/事件驱动更新。
7. 审计所有设置 pane 的同步文件、进程、系统查询，新增发现按范围进入本任务或另建任务。

## Implementation guidance

- 不创建通用数据层；用现有两个 ViewModel 的小型 async load/save 边界即可。
- 所有状态任务用 generation/cancellation，关闭窗口后不得继续发布到旧视图。
- T018 负责系统指标采样，本任务不重复搬迁 metrics。

## Acceptance criteria

- [ ] 设置首次显示和切页时 MainActor 不执行 `waitUntilExit`、同步模板遍历或大文件读写。
- [ ] Overview 停留不会每秒产生 `pluginkit` 子进程。
- [ ] slider 连续拖动流畅，写盘/通知次数被合并，松手或关闭窗口后最终值持久化。
- [ ] 离开输入增强页后状态 timer 停止；重新进入立即刷新。
- [ ] 权限状态与 T022 一致，不出现 Event Tap/输入监控含义混淆。
- [ ] Time Profiler 对比证明已消除已知主线程阻塞；设置 UI Tests 和完整 Debug 构建通过。
