# T011: 鼠标手势右键分界

## 元信息

- 优先级：P1
- 状态：REVIEW
- 推荐执行器：implementer
- 依赖：无

## Goal

对配置了右键手势的按钮，移动不超过 4pt 时保持普通右键；一旦移动超过 4pt，即使尚未识别方向也不得再回放右键。

## 范围

- `FewerCore/Services/InputProcessing.swift`
- `FewerCoreTests/InputProcessingTests.swift`
- `FewerShortcutHelper/EventTapController.swift`

## 要求

- 在纯 Core 层定义可测试的 4pt 判定及 completion 输入，覆盖边界值。
- `GestureSession` 保存已超过点击容差的不可逆状态；使用初始点与当前点的实际移动距离更新。
- completion 仅在未越过容差且未匹配规则时回放点击；超出容差但无方向/规则时静默结束。
- 取消、Escape、超时路径同样遵守该条件，不能产生重复点击。

## 排除项

- 不改变手势方向识别阈值、HUD 绘制、规则匹配或其他输入模块。
- 不修改 `.agent` 文件，不回退用户已有改动。

## 验证

- 新增 0、4、4+pt 与取消路径的 XCTest。
- 运行 FewerCore 测试。

## Completion Report

- 新增 `MouseGestureClickTolerance`，以实际欧氏距离判定是否超过 4pt。
- 手势会话一旦超过容差即不可逆；松开、Escape、超时及重置仅在未越界时回放右键。
- 新增 0pt、恰好 4pt、超过 4pt、斜向移动和 completion 回归测试。
