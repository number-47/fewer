# T004: CPU 模块

## 元信息

- 优先级：P1
- 状态：REVIEW
- 推荐执行器：implementer
- 依赖：T003

## Goal

实现 Stats 风格 CPU 模块的真实采样和弹窗详情，且 CPU 弹窗不包含快捷操作。

## 范围

- `FewerApp/Services/SystemMetricsService.swift`
- `FewerApp/Views/DashboardModuleView.swift`
- `FewerApp/App/FewerApp.swift`
- 确有必要的新 FewerApp CPU 适配器/视图文件。

## 要求

- 发布总 CPU、用户、系统、空闲、每核心、历史、load average 和运行时间；首次/异常采样显示不可用或无历史而不伪造数值。
- CPU 菜单栏 renderer 使用实际快照；支持 T002 的标签、百分比、折线、柱图、饼图、仪表盘偏好。
- CPU 弹窗展示总量、用户/系统/空闲、负载、运行时间、历史和核心明细；不出现快捷操作/模块命令区。
- 温度、频率、Apple Silicon 集群信息可使用可失败适配器；不能稳定读取时显示“不可用”，不得阻塞启动或使用伪造 0。
- 不能破坏 T008 的默认路由统计。

## 排除项

- 不加入 GPU、内存、磁盘采样，不改 project.yml 的 IOReport/SMC 链接，不实现进程列表或通知。
- 不修改 Core、ShortcutHelper、.agent 状态文件。

## 验证

- Fewer Debug build。
- 为纯 CPU 差分/格式化逻辑增加可行回归测试；完整 Core 测试。

## Completion Report

- 基于 host CPU 差分采样总/用户/系统/空闲、每核心、历史、load average 与 kern.boottime。
- CPU 菜单栏和弹窗使用可空快照；频率可失败，温度和集群显示不可用；无快捷操作。
- 验证：Fewer Debug build 和 258 个 Core tests passed。
