# T003: 共享菜单栏组件与状态项引擎

## 元信息

- 优先级：P0
- 状态：REVIEW
- 推荐执行器：implementer
- 依赖：T002

## Goal

以每个监控模块一个独立状态项替代旧 dashboard 状态项，按 `MonitorModulePreferences` 渲染可组合组件、弹窗容器和设置入口，并恢复完整 Fewer App 编译。

## 范围

- `FewerApp/App/FewerApp.swift`
- `FewerApp/Views/DashboardModuleView.swift`（可替换为通用监控视图）
- `FewerApp/Views/ModuleSettingsView.swift`
- `FewerApp/Views/GeneralSettingsView.swift`
- `FewerApp/Views/ToolboxPanelView.swift`
- 确有必要的新 FewerApp 监控组件/视图文件。

## 要求

- 删除所有 `dashboard`、`statusbarMetrics` 与旧聚合 `MetricsStatusView` 运行时依赖。
- 每个已启用且 `statusBarModuleIDs` 包含的 CPU/GPU/内存/磁盘/网络模块创建独立 `NSStatusItem`；日历继续独立状态项。
- 用共享 renderer 按偏好渲染 label、百分比、图形占位、容量/速率/状态/IP 等组件；无数据展示“—”，不得伪造 0。
- 提供每模块状态项开关、刷新间隔、组件选择/顺序、颜色、GPU 设备选择和类型显示的设置绑定；组件列表按 T002 允许的类型过滤。
- 弹窗通过统一容器承载模块视图；CPU 不显示快捷操作。日历仍直接承载 `MenuBarCalendarView`。
- 工具箱从旧“仪表盘”切换为五个监控入口，不移除截图、输入、Finder、系统快捷操作。

## 排除项

- 不实现 CPU/GPU/内存/磁盘/网络的完整采样或详情字段，不改 `SystemMetricsService` 的采样算法。
- 不修改 Core、ShortcutHelper、project.yml、.agent 协调文件。

## 验证

- Fewer Debug build。
- 现有 UI/Core 测试；`git diff --check`。

## Completion Report

- 以独立 CPU/GPU/内存/磁盘/网络状态项替换运行时 dashboard 状态项。
- 新增共享组件 renderer、统一监控弹窗和按模块持久化的设置控件；日历直接使用 `MenuBarCalendarView`。
- 删除运行时 `statusbarMetrics`/`MetricsStatusView` 依赖，工具箱替换为五个监控入口。
- 验证：Fewer Debug build succeeded，`git diff --check` passed。
