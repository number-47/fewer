# T017: 经签名验证的双向 XPC 命令通道

## Metadata

- Priority: P0
- Status: PENDING
- Dependencies: T028

## Goal

将 Helper 与 App 的特权命令迁到可校验双方身份的双向 XPC 连接；数据变更广播继续使用 DistributedNotificationCenter。

## Scope

- Helper/App 的 XPC 部署、有限命令协议、身份校验、重连和测试。
- 删除两个特权 DistributedNotificationCenter 命令通道；不修改普通状态广播。
- 禁止以共享 secret 或未认证通知伪造 XPC。

## Acceptance Criteria

- 签名架构探针证明命名 listener、双向往返、audit-token 身份校验和伪客户端拒绝。
- 未通过签名要求的本地进程不能触发截图、系统控制或输入切换命令。
- 连接中断不崩溃、不死锁、不无限排队，也不重复执行命令。

## Validation

- `xcodegen generate`
- Fewer Debug build、核心单元测试和签名 App/Helper 的双向与拒绝实机验证。

## Evidence

尚未开始；依赖 T028 的安全架构选择。
