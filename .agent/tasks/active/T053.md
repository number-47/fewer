# T053: 完善截图自动贴图

## Metadata
- Priority: P1
- Status: BLOCKED
- Dependencies: 无

## Goal

将截屏设置中的“自动贴图”从不支持占位项改为可用快速模式：截图完成后可跳过编辑，直接创建置顶贴图。

## Scope

- 复用现有 `ScreenshotAfterAction.pin` / `editThenPin` 设置，不新增持久化字段。
- 修改截屏设置页、普通截图完成分发、区域/窗口遮罩捕获和必要测试。
- 自动贴图仅影响普通区域、智能、窗口及全屏截图；不得改变 OCR 截图翻译流程。
- 保留关闭自动贴图时的现有编辑、复制、保存、滚动截图与手动贴图流程。

## Acceptance Criteria

- 设置页可开启或关闭“自动贴图”，状态持久化，不再显示“当前版本不支持”。
- 开启后，普通区域、智能、窗口、全屏截图在图像编码成功后直接创建浮动置顶贴图，不打开标注/结果窗口；区域截图因此不显示编辑工具栏中的滚动截图入口。
- 关闭后继续进入现有编辑流程；OCR 截图翻译始终保持现有流程。
- 设置文案明确自动贴图会跳过标注，以及区域截图的滚动截图入口。
- 设置模型回归测试、Fewer Debug 构建与 `git diff --check` 通过。

## Validation

- Fewer Debug 无签名构建。
