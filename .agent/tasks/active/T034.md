- 优先级：P2

## Goal

降低退出误触并补齐 Popover 键盘可访问性，不改变 Toolbox 信息架构。

## Requirements

- 标题栏保留 Activity、Settings、更多菜单；退出移入更多菜单，菜单含关于、诊断、打开日志、分隔线与退出。
- 提供焦点环、Tab、菜单箭头、`⌘,` 打开设置和 Esc 关闭。
- 不增加 Toolbox 一级入口，不增加页签持久化。

## Validation

- XCTest 覆盖菜单与键盘路径；签名实机键盘操作录屏。
