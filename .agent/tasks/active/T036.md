# T036: Input preference 主 App 单写迁移

## 元信息

- 优先级：P1
- 状态：BACKLOG
- 推荐执行器：implementer
- 依赖：T017, T030

## Goal

在 authenticated XPC 已可用后，将 Helper 的紧急禁用和按键展示位置变更提交给主 App，完成 Input preference 的主 App 单写迁移。

## Requirements

- Helper 不得直接写 Input preference；通过 T017 的受限 request/reply 提交 `emergencyDisabled` 与 custom keycast position。
- App 校验 payload、持久化到 App Group UserDefaults、发布非特权失效通知；Helper 仅更新本地运行时状态。
- 断线时不得无限排队或伪造写入成功；UI 显示可恢复的未保存状态。

## Validation

- 覆盖 authenticated 正向提交、非法 payload 拒绝、断线、重连及跨进程重新加载。
