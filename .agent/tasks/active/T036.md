# T036: Input preference 主 App 单写迁移

## Metadata

- Priority: P1
- Status: PENDING
- Dependencies: T017, T030

## Goal

在 authenticated XPC 可用后，将 Helper 的紧急禁用和按键展示位置变更提交给主 App，完成 Input preference 的主 App 单写迁移。

## Scope

- Helper 通过受限 request/reply 提交 `emergencyDisabled` 与 custom keycast position。
- App 校验 payload、写入 App Group UserDefaults 并发布非特权失效通知；Helper 只更新运行时状态。
- 断线时不无限排队、不伪造成功，UI 显示可恢复的未保存状态。

## Acceptance Criteria

- 覆盖 authenticated 正向提交、非法 payload 拒绝、断线、重连及跨进程重新加载。
- Helper 不直接写 Input preference，主 App 是唯一写者。

## Validation

- 运行上述协议与跨进程重载测试。

## Evidence

尚未开始；等待 T017 的 authenticated XPC 和 T030 的共享 Store。
