# T056: 截图翻译结果窗按需滚动

## Metadata

- Priority: P1
- Status: BLOCKED
- Dependencies: T046

## Goal

让截图翻译结果窗展示识别原文与译文；仅当可用高度不足以容纳完整内容时才显示滚动容器。

## Scope

- 修改结果视图、Apple Translation 结果区布局与必要测试；不修改翻译请求或状态机。
- 不向结果窗传递或保留截图图像；不得写入文件、设置、日志或网络。
- 保留原文复制、译文复制、翻译源、目标语言、重试、设置和固定窗口行为。
- 不修改 OCR 识别、Apple Translation、AI 请求、截图设置或普通截图流程。

## Acceptance Criteria

- 有 OCR 结果时，浮窗展示识别原文和译文内容，但不展示截图图片。
- 内容在当前窗口高度内放得下时没有滚动条；放不下时对应文本区可滚动，不裁切控件或文本。
- 原文区与译文区始终同时可见；各自仅在分配高度不足时滚动，不因原文较长而将译文推到可视区外。
- 结果窗默认使用 OCR 所在屏幕可见区域高度的 85%（最低 500pt），并始终受可见区域上限约束。
- 截图图像不进入结果窗的内存生命周期。
- `git diff --check` 通过；Fewer Debug 构建与 macOS 26 签名交互矩阵通过后方可归档。

## Validation

- Fewer Debug 无签名构建。
- `python3 script/verify_agent_state.py`
- `git diff --check`
- macOS 26 签名运行：短内容无滚动条；受限高度或长内容出现单一内容滚动；原文、译文、复制、翻译源、目标语言、重试、设置、固定、关闭和连续 OCR 均正常。
