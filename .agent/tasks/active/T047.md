# T047: macOS 26 部署基线与运行时证据收口

## Metadata

- Priority: P1
- Status: BLOCKED
- Dependencies: T046

## Goal

将 Fewer 最低部署版本迁移至 macOS 26，并记录 OCR 截图翻译的 macOS 26 代码与运行时证据层级。

## Scope

- 修改 `project.yml`、`Config/Base.xcconfig`、macOS 26 SDK 所必需的全屏截图实现、必要测试与 XcodeGen 生成物。
- 不移除既有 Translation 可用性保护、不改变发布/XPC/Finder 门禁、不实现新产品能力。

## Acceptance Criteria

- `project.yml` 与 `Base.xcconfig` 均声明 macOS 26.0，XcodeGen 生成工程一致。
- macOS 26 本机构建、测试与签名 Debug 启动均成功。
- 最终证据分别列出：自动化构建/测试、签名设置入口、物理全局按键/OCR/Translation 与多显示器结果；后两项不能用合成事件替代。

## Validation

- `xcodegen generate`、`./script/verify.sh`、`./script/build_and_run.sh --verify`、`git diff --check`。
