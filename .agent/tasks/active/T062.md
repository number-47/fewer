# T062: 系统监控历史记录轻量化

## Metadata

- Priority: P1
- Status: BLOCKED
- Dependencies: T018

## Goal

系统监控历史只保存图表展示所需的轻量数据，避免一小时内重复保留完整快照和进程列表。

## Scope

- 增加轻量历史点类型，保存时间、CPU/GPU/内存、磁盘和网络图表所需字段。
- `current` 继续保留完整 `SystemMetricsSnapshot`；采样器、刷新间隔和当前进程列表不变。
- 更新图表读取轻量历史，不改变一小时窗口和用户可见展示。
- 增加历史映射、裁剪和边界测试。
- 不增加持久化、数据库、长期历史或新配置。

## Acceptance Criteria

- 历史数组不再持有 CPU/GPU/内存进程列表或其他非图表详情。
- CPU、GPU、内存、磁盘和网络趋势图的数据语义与当前实现一致。
- 历史仍只保留最近一小时，空值和 GPU 设备切换行为明确。
- 当前快照、采样调度、进程终止和模块显示行为不变。
- 相关测试、`git diff --check`、状态校验和 Fewer Debug 构建通过。

## Validation

- 相关 FewerCore XCTest。
- `python3 script/verify_agent_state.py`
- `git diff --check`
- Fewer Debug 无签名构建。

## Evidence

- 2026-09-04：任务开始前 `SystemMetricsService.history` 保存完整 `SystemMetricsSnapshot` 一小时；每个元素重复持有 CPU/GPU/内存详情和三组进程列表。生产历史消费者只读取 CPU 总利用率、按设备 GPU 利用率、内存比例、磁盘使用率/读写速度和网络速率。
- 2026-09-04：新增 `MonitorHistoryPoint` 与 `MonitorDiskHistoryPoint`，历史仅保留时间、CPU、按设备 GPU、内存、磁盘图表字段和网络速率；当前完整快照、采样配置、进程列表和进程终止入口保持不变。GPU 历史继续按当前设备 ID 读取，切换设备时不会混用其他 GPU 数据。
- 2026-09-04：历史裁剪改为只移除有序数组开头超过一小时的元素，不再每个 tick 对完整快照数组执行 `removeAll`。现有菜单栏图表和监控详情已切换到轻量历史；新增 GPU 查找、一小时边界和未来时间点测试。
