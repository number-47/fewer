# T061: 设置窗口跟随系统深浅色

## Metadata

- Priority: P1
- Status: BLOCKED
- Dependencies: 无

## Goal

让设置窗口跟随系统浅色或深色外观，并保持所有页面内容、选中态和控件可读。

## Scope

- 移除设置根视图强制浅色。
- 将设置页面的硬编码白色背景、浅色侧栏和浅色边框替换为 macOS 语义颜色。
- 保留现有布局、尺寸、导航、蓝色强调色和设置行为。
- 不增加独立主题设置，不修改菜单栏面板、截图窗口或业务逻辑。

## Acceptance Criteria

- 系统浅色下设置窗口保持现有清晰层级。
- 系统深色下根背景、侧栏、卡片、列表行、边框、主次文字和选中态均清晰可读。
- 系统切换外观后已打开的设置窗口自动更新。
- 设置导航、输入、开关、列表拖拽和提醒行为不变。
- `git diff --check`、状态校验和 Fewer Debug 构建通过；真实深浅色交互核对完成。

## Validation

- `python3 script/verify_agent_state.py`
- `git diff --check`
- Fewer Debug 无签名构建。
- macOS 26 中打开设置窗口并切换系统浅色/深色，核对所有设置页面。
