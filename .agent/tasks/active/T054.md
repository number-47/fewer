# T054: OCR 翻译浮窗外部点击关闭与固定

## Metadata
- Priority: P1
- Status: BLOCKED
- Dependencies: T046

## Goal

让 OCR 翻译结果浮窗默认在用户点击窗外后自动关闭，并允许用户固定窗口以持续置顶查看。

## Scope

- 修改 OCR 翻译窗口控制器、视图状态与必要测试。
- 默认未固定；点击其他窗口、桌面或其他应用后关闭，并沿用现有 dismiss 清理 OCR 文本和翻译任务。
- 浮窗提供明确的固定/取消固定按钮；固定后继续置顶且失去焦点不关闭，取消固定后恢复自动关闭。
- 新一轮 OCR 截图仍替换当前结果窗口；固定状态不持久化、不允许保留多份 OCR 文本。
- 不修改 OCR、Apple Translation、AI 请求、语言选择、窗口位置设置或普通截图贴图流程。

## Acceptance Criteria

- 新 OCR 结果窗默认未固定，点击窗外后关闭并清理当前会话。
- 固定按钮状态清晰可见；固定时点击窗外不关闭，再次取消固定后下一次窗外点击关闭。
- 点击浮窗内部的复制、翻译源、目标语言、重试、设置和固定按钮不会被当作窗外点击。
- 手动关闭和新 OCR 请求继续执行现有清理/替换逻辑；固定状态不写入任何持久化存储。
- Fewer Debug 构建、`git diff --check` 与 macOS 26 签名交互矩阵通过。

## Validation

- Fewer Debug 无签名构建。
- `python3 script/verify_agent_state.py`
- `git diff --check`
- macOS 26 签名运行中验证：窗内各控件、点击其他 Fewer 窗口、桌面和其他应用；固定、取消固定、手动关闭及连续 OCR。
