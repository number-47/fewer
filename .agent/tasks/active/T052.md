# T052: AI 截图翻译的兼容服务与签名运行时验收

## Metadata
- Priority: P1
- Status: BLOCKED
- Dependencies: T051

## Goal
以本机 OpenAI-compatible 桩服务验证签名 Debug 的 AI 翻译真实请求边界，并与现有截图翻译运行时证据分层记录。

## Scope
- 仅增加必要的测试夹具/验证脚本与任务证据；不改变产品能力。
- 覆盖保存并测试、成功译文、鉴权失败、限流、超时、无效 JSON、取消和目标语言重译。

## Acceptance Criteria
- 签名 Debug 通过本机兼容服务完成系统默认、手动切 AI、显示译文和目标语言切换；服务仅收到文本和语言参数。
- 物理全局按键、屏幕录制、Apple Translation、多显示器与真实外部供应商证据独立记录，未完成不得误报。

## Validation
- xcodegen generate、./script/verify.sh、./script/build_and_run.sh --verify、git diff --check，以及人工签名 Debug 矩阵。

## Evidence
