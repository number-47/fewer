# T018: PR6 — SystemMetrics 后台采样与频率分层

## 元信息

- 优先级：P1
- 状态：BACKLOG
- 推荐执行器：implementer
- 依赖：T013

## Goal

把 Mach、sysctl、IOKit、文件系统和 `/sbin/route` 等阻塞采样移出 MainActor；主线程只发布不可变 snapshot，并按模块配置实际需要的采样频率。

## Context

`SystemMetricsService` 整体为 `@MainActor`，timer 同步调用 `sample()`；其中包含多个系统调用、IOKit 遍历和 `Process.waitUntilExit()`。原 PR4 把该性能改造与 XPC 安全边界混在一起，无法独立回滚。

## Implementation steps

1. 保留 `@MainActor ObservableObject` 作为 UI facade；把采样状态和阻塞方法移入非 MainActor 的 worker actor/串行执行器。
2. Timer 只触发异步请求；同一轮未完成时合并 tick，禁止并发采样和无界排队。
3. worker 返回 Sendable snapshot 后在 MainActor 一次性发布；停止/配置变化用 generation token 丢弃过期结果。
4. CPU/网络保持高频，GPU/SMART/磁盘按各自配置低频复用最近值；模块停用后不再采样。
5. 本 PR 不改默认路由选择语义；`/sbin/route` 即使暂时保留，也必须不再阻塞 MainActor。

## Acceptance criteria

- [ ] 采样调用链中 Mach/sysctl/IOKit/Process/磁盘访问均不在 MainActor。
- [ ] 慢采样期间菜单栏和设置界面仍可响应；timer 不重入、不堆积。
- [ ] 测试覆盖频率分层、停用模块、过期结果丢弃和慢采样合并。
- [ ] 默认路由/VPN、计数器 baseline 和“不可用而非伪造 0”语义不回归。
- [ ] 签名运行日志或 Instruments 证据确认主线程无采样阻塞。
