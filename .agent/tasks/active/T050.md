# T050: OCR 翻译结果窗位置、展开与目标语言修复

## Metadata

- Priority: P0
- Status: BLOCKED
- Dependencies: T046

## Goal

让 OCR 翻译结果窗支持选区附近或当前屏幕固定位置配置，默认尽量展开原文与译文，并确保目标语言选择器始终有有效选中项。

## Scope

- 修改截图设置模型、截图设置页、OCR 窗口布局/控制器、翻译视图与必要测试。
- “固定位置”使用当前 OCR 选区所在屏幕的预设锚点；保留现有浮动置顶行为，不新增自由拖拽坐标持久化。
- 保持 OCR 文本与译文仅存在当前会话；不修改截图捕获、Vision OCR、Translation 服务边界或其他模块。

## Acceptance Criteria

- 截图设置页可选择“选区附近”及九个屏幕固定位置；旧设置缺少字段时回退“选区附近”。
- OCR 结果窗按配置定位，并始终约束在当前屏幕可见区域内。
- 结果窗默认尺寸和原文/译文布局尽量利用当前屏幕空间，普通长度内容无需滚动，超长内容仍可滚动。
- Translation 支持语言加载后，目标语言选择器匹配规范化语言代码；首选目标不可用时选择一个与源语言不同的有效目标。
- 既有目标语言切换会作废旧翻译 generation，OCR 文本不被清空。

## Validation

- `OCRTranslationWindowSupportTests` 与 `ScreenshotModelsTests` 相关 XCTest。
- Fewer Debug 无签名构建。
- `git diff --check`。
- 真实设置页、窗口位置、内容展开和 Translation 选择器交互需在 macOS 26 签名运行中验证；构建不能替代。
