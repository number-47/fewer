# T028: 签名 XPC 架构探针

## Metadata

- Priority: P0
- Status: BLOCKED
- Dependencies: T027

## Goal

在签名 GUI 实机上确定 Helper 的 Mach service 部署拓扑，并记录双向、身份校验、重连及伪客户端拒绝证据。

## Scope

- 验证现有 Login Item；若必要，单独验证 `SMAppService.agent` 的 GUI/Event Tap/HUD 行为。
- listener 必须用 audit token 校验 Team ID、bundle ID、designated requirement 和 App Group entitlement。
- 不修改生产特权命令通道，也不以未认证通知替代。

## Acceptance Criteria

- 记录签名、launchd、双向往返、重连和伪客户端拒绝的可复现证据。
- Helper 输入与 HUD 行为不退化。

## Validation

- 保存签名、launchd 和正向/反向 ping/reply、重连与拒绝日志。

## Evidence

- 2026-08-25：签名 Debug App、Finder Extension 和 Shortcut Helper 使用 Team ID `6P34MCYUCS` 与同一 App Group；Login Item 已登记但 job 为 `spawn failed`，源码没有 `NSXPCListener`。
- 当前 macOS 26.5 SDK 的公开 `NSXPCConnection` 不提供 audit token；以 PID 获取 `SecCode` 不满足本任务验收，因此未采用。
- 解除条件：用户选择允许采用保留 audit token 的低层 `xpc_connection_t` listener，或明确调整 audit-token 安全验收。选择前不得修改生产 DNC 特权通道。
