# T059: 截图识别并复制

## Metadata

- Priority: P1
- Status: BLOCKED
- Dependencies: T046

## Goal

增加“截图识别并复制”入口，用户选择屏幕区域后使用现有 Vision OCR 识别文字并复制到系统剪贴板。

## Scope

- 复用现有截图区域选择、屏幕录制权限、OCR 图像预算、Vision OCR 和 OCR 阅读顺序。
- 增加独立 capture purpose、模块命令和必要的核心测试。
- 成功时只将识别出的非空文本写入系统剪贴板并展示简短反馈；失败或无文字时不覆盖现有剪贴板。
- 不打开翻译结果窗，不启动 Apple Translation 或 AI，不增加全局快捷键，不持久化或记录 OCR 文本。
- 不修改普通截图、滚动截图、截图翻译或自动贴图行为。

## Acceptance Criteria

- 截图模块出现“识别并复制”命令，选择区域后识别文字并复制。
- OCR 结果为空或识别失败时保留原剪贴板并给出明确反馈。
- 新请求、取消和快速连续触发不会让旧识别结果覆盖剪贴板。
- OCR 文本不进入日志、UserDefaults、App Group、文件、翻译服务或网络。
- 现有截图翻译、普通截图和快捷键行为不变。
- 核心测试、`git diff --check`、状态校验和 Fewer Debug 构建通过；签名实机完成屏幕录制交互核对。

## Validation

- 相关 FewerCore XCTest。
- `python3 script/verify_agent_state.py`
- `git diff --check`
- Fewer Debug 无签名构建。
- macOS 26 签名运行：成功识别、无文字、失败、取消、连续触发及剪贴板保留矩阵。

- 2026-09-04：新增独立 `.ocrCopy` capture purpose 和截图模块“识别并复制”命令；遮罩继续只允许区域选择，提示明确说明识别后复制。未增加全局快捷键，普通截图与截图翻译入口保持原样。
