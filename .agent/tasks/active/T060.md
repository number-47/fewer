# T060: Finder 批量重命名

## Metadata

- Priority: P1
- Status: BLOCKED
- Dependencies: T016

## Goal

在 Finder 选中多个项目时提供批量重命名，支持安全预览并执行可验证、无静默覆盖的文件名变更。

## Scope

- 增加 Finder 菜单功能开关、命令、预览输入界面、纯值重命名规划和文件执行逻辑。
- 第一版支持查找替换、前缀、后缀和可选顺序编号；保留文件扩展名。
- 执行前展示旧名称与新名称；拒绝空名称、路径分隔符、重复目标和与未选中项目冲突。
- 支持同一目录内的名称互换或循环重命名，执行失败时尽力回滚并给出汇总。
- 不静默覆盖文件，不修改剪切粘贴、模板、打开方式、Finder 扩展覆盖范围或 entitlement。

## Acceptance Criteria

- 仅在 Finder 选中至少两个项目时显示“批量重命名”。
- 用户可配置查找替换、前缀、后缀和顺序编号，并实时查看预览。
- 无效或冲突方案不能执行，且原因可读。
- 有效方案完成后 Finder 刷新；部分失败时报告失败项且不声称全部成功。
- 核心规划与执行逻辑覆盖成功、无变化、非法名称、重复、外部冲突、互换及回滚路径。
- 相关测试、`git diff --check`、状态校验和 Finder Extension 构建通过；签名 Finder 实机矩阵通过。

## Validation

- 相关 FewerCore XCTest。
- `python3 script/verify_agent_state.py`
- `git diff --check`
- FewerFinderExtension/Fewer Debug 无签名构建。
- macOS 26 签名 Finder：多文件、多目录、扩展名、冲突、名称互换、取消和失败反馈。

## Evidence

- 2026-09-04：现有 Finder 菜单通过 `FewerFeature`、`MenuBuilder` 和不可变 action snapshot 分发命令，文件修改集中在 `FileOperationCoordinator`。批量重命名应沿用该入口，规划阶段先拒绝非法名称、重复目标和外部冲突，执行阶段用同目录临时名称支持互换与循环。
- 2026-09-04：新增批量重命名功能开关、Finder 命令和 SwiftUI 预览输入，支持查找替换、前缀、后缀与可选顺序编号；至少选择两个项目时显示，只读目标下禁用。v5 配置迁移到 v6 时默认启用并追加到用户既有排序末尾。
- 2026-09-04：新增纯值 `BatchRenamePlanner`，保留文件扩展名并拒绝空名称、`.`、`..`、路径分隔符、重复目标、未选中项目冲突和无变化方案。执行阶段先将变更项移动到同目录唯一临时名称，再安装目标名称，因此支持名称互换与循环且不会静默覆盖。
- 2026-09-04：安装或暂存失败时会尝试恢复所有原名称；完整恢复与恢复不完整使用不同结果和 Finder 提示，不会把部分失败报告为全部成功。完成或失败后通知 Finder 刷新涉及目录，未修改 Finder 覆盖范围、entitlement、剪切粘贴、模板或打开方式。
- 2026-09-04：补充配置迁移、菜单显示/关闭/只读状态、扩展名保留、空名称、无变化、非法名称、重复目标、外部冲突、名称互换和安装失败回滚测试。`python3 script/verify_agent_state.py`、`git diff --check`、命令穷举检索和批量重命名静态审查通过。
- 2026-09-04：当前 WSL 没有 Swift/Xcode 工具链，不能执行 FewerCore XCTest、FewerFinderExtension/Fewer Debug 构建或签名 Finder 实机交互。
