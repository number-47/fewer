# T030: App Group identifier 与跨进程 Store

## 元信息

- 优先级：P1
- 状态：DONE
- 推荐执行器：implementer
- 依赖：T027

## Goal

固定 Team-ID App Group，并消除多个进程对共享 JSON 的 lost-update 风险。

## Requirements

- 正式运行时只使用 `$(DEVELOPMENT_TEAM).group.com.number47.fewer`；legacy group 仅用于一版迁移读取，Release container 缺失必须可诊断且使发布验收失败。
- Feature、Module preferences 使用 App Group `UserDefaults`，主 App 是唯一写者，Finder/Helper 只读；DNC 仅通知失效。Input preference 的 Helper 写入迁移由 T036 在 T017 后完成，本任务不得静默禁用既有持久化。
- Cut transaction 等多写 JSON 使用同一跨进程锁、`NSFileCoordinator`、revision envelope 和原子替换；诊断/Helper status 保持单写者。
- 保留旧数据一个发布周期，迁移不覆盖已存在新值。

## Validation

- Core 多实例/多进程并发、迁移、revision 冲突与三 target 同容器探针。

## Completion Report

- Feature、Module preference 已迁至 App Group UserDefaults，旧 JSON 只在新值缺失时迁入且保留原文件。
- Release 缺失 App Group container 现为 fail-closed，Debug 保留本地 fallback；legacy identifier 仅迁移读取。
- Cut transaction 使用 flock、NSFileCoordinator、revision envelope 与原子写；已加入真实独立子进程锁阻塞测试。
- 通过独立审查和 `./script/verify.sh`：356 Core tests/0 failures、完整 Debug build、模板/产物/drift 检查通过。
- Helper 的 emergency/keycast Input 写入保留给 T036 在 authenticated XPC 后迁移，避免提前只读化导致行为丢失。
