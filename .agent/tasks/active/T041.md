# T041: 修复进程关闭元数据误判

## Metadata

- Priority: P1
- Status: IN_PROGRESS
- Dependencies: T040

## Goal

修复正常关闭进程时因名称或路径读取结果变化而错误提示“进程名称或路径已经变化，已取消退出操作”。

## Scope

- 关闭前继续用 PID + `ri_proc_start_abstime` 验证进程实例，保留 PID 复用保护。
- 名称和路径仅用于展示与系统进程分类，不再作为关闭时的强身份条件。
- 不改变普通/系统进程确认策略，不加入强制退出、管理员权限或新依赖。
- 仅修改进程关闭服务及必要证据，不改采样、Top 5 排序或弹窗布局。

## Acceptance Criteria

- 同一 PID 且启动时间一致时，即使名称或路径读取结果为空、解析方式不同或发生展示变化，仍可发送正常退出。
- PID 已退出、不可读取或启动时间不同仍明确拒绝，不能误杀复用 PID。
- 不再出现 `processMetadataChanged` 错误分支。
- FewerCore 测试、Fewer Debug 构建与 `git diff --check` 通过。

- 签名运行后从 Top 5 关闭一个可安全退出的普通应用或测试进程，确认不再触发元数据变化提示。
