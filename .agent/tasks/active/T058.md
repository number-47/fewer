# T058: 日历年月选择快速切换

## Metadata

- Priority: P1
- Status: BLOCKED
- Dependencies: 无

## Goal

在菜单栏日历的年月选择弹窗中增加前后按钮，支持快速切换年份和月份。

## Scope

- 修改现有 `CalendarMonthPickerView` 及必要测试或验证证据。
- 年份按钮每次切换一年；月份按钮每次切换一个月并正确跨年。
- 保留现有 1900–2100 年范围、Picker、取消和跳转行为。
- 不修改日历事件读取、浏览状态持久化、菜单栏布局或系统权限。

## Acceptance Criteria

- 年份选择器左右均有按钮，可在 1900–2100 范围内前后切换一年，边界不可越界。
- 月份选择器左右均有按钮，可前后切换一个月；1 月向前切换到上一年 12 月，12 月向后切换到下一年 1 月。
- 月份跨年时仍遵守 1900–2100 年边界。
- 按钮具有明确帮助文本和辅助功能标签，现有 Picker、取消和跳转继续可用。
- `git diff --check`、状态校验和 Fewer Debug 构建通过；真实菜单栏年月弹窗交互完成核对。

## Validation

- `python3 script/verify_agent_state.py`
- `git diff --check`
- `xcodebuild -project Fewer.xcodeproj -scheme Fewer -configuration Debug -derivedDataPath .build/DerivedData SYMROOT="$PWD/.build/DerivedData/Build/Products" OBJROOT="$PWD/.build/DerivedData/Build/Intermediates.noindex" CODE_SIGNING_ALLOWED=NO build | xcbeautify`
- macOS 26 签名运行中核对年份、月份、跨年边界、取消与跳转。

## Evidence

- 2026-09-04：任务开始前工作区干净。现有 `CalendarMonthPickerView` 只有年份和月份 Picker，没有快速切换按钮；可选年份固定为 1900–2100。
- 2026-09-04：年月弹窗改为两行快速选择：年份和月份 Picker 左右分别增加前后按钮。年份按钮每次移动一年；月份按钮每次移动一个月，1 月向前和 12 月向后会同步调整年份。
- 2026-09-04：1900 年 1 月的上个月按钮、1900 年的上一年按钮、2100 年 12 月的下个月按钮和 2100 年的下一年按钮会禁用；四个按钮均提供帮助文本、辅助功能标签和稳定标识。现有 Picker、取消、跳转和弹窗调用路径保持不变。
- 2026-09-04：主对话审查确认仅修改 `CalendarMonthPickerView` 和任务状态，没有改变日历事件读取、浏览状态、菜单栏主体布局、权限或持久化；未发现范围内 P0/P1/P2 问题。
