# T029: Finder `/` 例外移除与实机矩阵

## 元信息

- 优先级：P0
- 状态：BLOCKED
- 推荐执行器：implementer
- 依赖：T027, T016

## Goal

删除 Finder Extension 的根路径 temporary exception，并以签名实机矩阵证明 Finder 文件操作仍可用。

## Requirements

- 从 entitlements 与 `project.yml` 移除 `/` read-write exception，重新生成工程。
- 签名实机覆盖 `/Users` 与外置卷的 create、cut/paste、keepBoth、skip、replace、template、open、refresh。
- 失败时恢复工作树并标记 BLOCKED，给出主 App 或用户授权访问的重新设计证据；不得保留例外后宣称完成。
