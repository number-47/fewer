# T029: Finder 根路径例外移除与实机矩阵

## Metadata

- Priority: P0
- Status: BLOCKED
- Dependencies: T027, T016

## Goal

删除 Finder Extension 的根路径临时例外，并以签名实机矩阵证明 Finder 文件操作仍可用。

## Scope

- 移除 entitlements 与 `project.yml` 中的根路径 read-write exception，并重新生成工程。
- 在签名实机覆盖 `/Users` 与外置卷的 create、cut/paste、keepBoth、skip、replace、template、open、refresh。
- 失败时保留证据并重新设计权限边界；不得保留例外后宣称完成。

## Acceptance Criteria

- 最新签名 Extension 在支持路径的文件操作矩阵通过。
- 最终产物不含根路径例外，且失败场景有准确证据。

## Validation

- `xcodegen generate`
- `./script/build_and_run.sh run`
- `codesign -d --entitlements :- .build/DerivedData/Build/Products/Debug/Fewer.app/Contents/PlugIns/FewerFinderExtension.appex`

## Evidence

- 2026-08-25：`pluginkit` 显示启用的 Finder Extension 来自 `/Applications/Fewer.app`，不是当前 `.build` 签名产物。
- 覆盖 `/Applications/Fewer.app` 才能测试最新 Extension，属于覆盖用户安装的外部写入，尚未执行。
- 解除条件：获得明确授权并完成当前签名 Extension 的覆盖安装和启用，随后执行完整文件操作矩阵。
