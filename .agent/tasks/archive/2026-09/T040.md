# T040: CPU/GPU/内存进程 Top 5 与关闭操作

## Metadata

- Priority: P1
- Status: DONE
- Dependencies: 无

## Goal

在 CPU、GPU、内存菜单栏独立弹窗中展示对应占用最高的 5 个进程，并允许从行首悬浮关闭图标退出进程。

## Scope

- 在现有 `SystemMetricsSampler` actor 中后台采样进程数据，不在 MainActor 启动高频外部进程。
- CPU 使用 `libproc` 累计 CPU 时间差值，内存使用 physical footprint/resident size；GPU 在 Apple Silicon 上尽力读取 `AGXDeviceUserClient` 的 `IOUserClientCreator` 与 `AppUsage.accumulatedGPUTime` 差值。
- CPU、GPU、内存各发布 Top 5；GPU 数据源不可用或首次无基线时明确显示不可用/等待采样，不伪造数值。
- 进程行最左侧平时显示排名，鼠标悬浮时显示关闭图标。普通用户进程点击后直接正常退出；系统进程点击后先确认再正常退出。
- 系统进程保守判定为非当前用户、可执行文件位于系统目录或关键系统进程名称；PID 0/1 与 Fewer 自身不可关闭。优先 `NSRunningApplication.terminate()`，非应用进程发送 `SIGTERM`；不自动 `SIGKILL`，失败显示原因。
- 保持 280pt 宽度、既有监控卡片和无滚动条要求；仅增加 CPU/GPU/内存面板所需高度，不修改磁盘、网络、Toolbox、日历或偏好模型。
- 保留当前工作区 T037-T039/T038 未提交改动，不覆盖无关 dirty 文件；不新增依赖、target 或管理员权限通道。

## Acceptance Criteria

- CPU Top 5 按最近采样区间 CPU 百分比降序，允许多核进程超过 100%；首次采样不把累计时间误当瞬时占用。
- 内存 Top 5 按 physical footprint（不可用时 resident size）降序并使用字节格式化展示。
- Apple Silicon GPU Top 5 按 `accumulatedGPUTime` 的区间差值降序；相同 PID 的多个 user client 聚合；不支持时安全降级。
- 三类列表最多 5 行，显示排名、进程名、PID 与占用值；最左侧仅悬浮时出现关闭图标。
- 普通进程点击关闭图标直接发送正常退出；系统进程显示包含名称/PID 的确认；PID 0/1 和 Fewer 自身不可关闭；失败有可见错误。
- CPU/GPU/内存弹窗保持无滚动条且底部工具入口可见。
- 回归测试覆盖排序/限制、差值基线、GPU PID 聚合/解析、系统进程分类与禁止关闭规则；FewerCore 测试和 Fewer Debug 构建通过，签名实机完成三类弹窗与可撤回测试进程的关闭交互。
