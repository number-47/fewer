# T044: OCR 原文与翻译结果浮窗

## Metadata

- Priority: P0
- Status: DONE
- Dependencies: T043

## Goal

在 OCR 完成后显示轻量、可复制的原文/译文上下浮窗，并正确管理窗口和 OCR 任务生命周期。

## Scope

- 新增 OCR 翻译窗口控制器、SwiftUI 视图和主线程 coordinator/view model，并修改 `ScreenshotService` 将 T043 的中间 OCR 状态接入它；新增 App Swift 源后运行 `xcodegen generate` 并仅纳入对应工程生成物。
- 原文可选中/复制，译文区支持准备中、翻译中、失败和不可用状态；不在本任务接入真实翻译请求。
- 窗口优先放在选区右侧，空间不足时左侧/下方，并限制于目标屏幕 visible frame。

## Acceptance Criteria

- OCR 完成后立即显示原文与“正在翻译”占位；原文复制只在用户点击时写剪贴板。
- 新截图关闭旧窗口并取消旧 OCR/翻译 generation；窗口关闭后释放会话文本。
- 无文字不打开空窗口，改显示短暂“未识别到文字”反馈。
- 窗口可交互、可 Cmd-W 关闭，且不会在失焦时自动消失。

## Validation

- 浮窗布局/位置计算和状态迁移的 XCTest。
- FewerCore 测试、Fewer Debug 无签名构建、`git diff --check`。
- 签名 Debug 原文显示/复制、靠右与靠底 clamp、连续触发由 T046 在 Apple Translation 和完整错误状态接通后统一执行；不得以本任务无签名构建替代该实机验收。
