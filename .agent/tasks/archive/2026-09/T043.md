# T043: 截图翻译选区、快捷键与 Vision OCR 链路

## Metadata

- Priority: P0
- Status: DONE
- Dependencies: T042

## Goal

复用现有截图遮罩，让独立快捷键进入仅区域选择的端侧 OCR 捕获链路，而不改变普通截图行为。

## Scope

- 修改 `HotKeyManager`、`ScreenshotService`、`CaptureOverlayView`；新增 OCR 模型、阅读顺序、Vision service、最小 coordinator 及测试/fixtures；新增 App Swift 源后运行 `xcodegen generate` 并仅纳入对应 `Fewer.xcodeproj` 生成物。
- 以 capture intent/purpose 表达截图后用途；不得向 `ScreenshotMode` 增加 OCR 或翻译 case。
- OCR 选区松开后关闭遮罩并将原始 `CGImage` 交给 Vision，不进入调整选区、滚动截图或 Markup Editor。
- 本任务不实现翻译窗口、Apple Translation 或模块菜单。

## Acceptance Criteria

- Command-Option-T 注册为独立 OCR 翻译动作，禁用截图快捷键时不注册。
- 普通区域、窗口和全屏截图保持既有路径。
- OCR 翻译仅允许区域选择，Esc 取消仍可用；选区完成后的异步回调受现有 session gate 保护。
- 遮罩消失后再捕获，且 Vision 在主线程外生成包含阅读顺序、置信度、bounding box 与语言代码的 OCR 结果。
- 无文字和 OCR 失败产生明确的 coordinator 状态，不记录图片、OCR 文本或译文；取消或过期任务不得回写最新会话。

## Validation

- 覆盖热键动作映射、capture intent/session gate、阅读顺序与 OCR 模型的 XCTest；稳定 fixture 只断言关键片段/空结果，不锁死 Vision 全文。
- FewerCore 测试、Fewer Debug 无签名构建、`git diff --check`。
- Command-Option-T、Esc、英文/中文 OCR 与普通截图的签名 Debug 交互，由 T046 在结果浮窗与连续触发均已接通后执行一次完整端到端矩阵；本任务不以没有可见结果界面的中间链路重复操作验证替代该矩阵。
