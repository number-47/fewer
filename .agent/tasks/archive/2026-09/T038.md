# T038: 日历独立菜单栏弹窗精修

## Metadata

- Priority: P1
- Status: DONE
- Dependencies: 无

## Goal

依据参考图重做日历独立菜单栏弹窗，在大尺寸卡片式界面中展示月历、选中日期摘要和真实系统日程，并保留刷新与设置入口。

## Scope

- 精修日历独立菜单栏弹窗的容器、标题栏、月历卡片和事项卡片，并为显式刷新增加最小的系统事件缓存失效入口；工具箱内嵌日历保持现有紧凑布局。
- 复用 `CalendarViewState`、`CalendarMonth` 与 `SystemCalendarService`，不写入参考图中的示例日程、地点或数量。
- 保留月份切换、日期选择、滚轮逐周、权限提示和月份选择器；不新增系统权限或第三方依赖。

## Acceptance Criteria

- 独立弹窗按参考图使用约 710pt 固定宽度、最高 910pt，高度受屏幕空间约束时内容可滚动。
- 标题栏包含蓝色日历图标、标题/副标题，以及有稳定可访问性标识的“刷新”和“设置”按钮。
- 月历使用卡片外观、居中的年月标题、左右月份切换、7 列星期、农历/节假日文本、圆形选中日期和底部选中日期摘要。
- 事项区按真实选中日期展示标题、数量和卡片行；行内使用真实标题、时间范围、日历名称/事项类型，不虚构地点或会议信息；无权限、无事项和加载状态仍有明确反馈。
- 工具箱内嵌日历的尺寸和紧凑信息架构不回归；设置按钮打开 Fewer 设置，刷新按钮重新加载当前可见月的系统事项。
- FewerCore 测试和 Fewer Debug 构建通过；签名 Debug 的独立日历弹窗完成尺寸、月份切换、日期选择、刷新和设置入口真实交互核对。
