# T039: 修复监控弹窗系统信息与高度

## Metadata

- Priority: P1
- Status: DONE
- Dependencies: 无

## Goal

修复菜单栏监控弹窗中的 Wi-Fi、GPU、Swap、磁盘 SMART 数据展示，并调整五类监控弹窗高度，使完整内容不出现滚动条。

## Scope

- 修复 `NetworkWiFiDetailsService` 的定位授权回调与当前 Wi-Fi 读取。
- 修复 Apple Silicon GPU 类型、核心数与可用状态的 IOKit 字段解析。
- Swap 沿用系统真实值；系统未分配交换文件且 total/used/free 全为 0 时显示“未使用”，不伪造非零数据。
- 为启动卷 SMART 健康状态增加系统公开 `diskutil info -plist` 降级读取，保留现有 IOKit 详情字段。
- 调整 CPU、GPU、内存、磁盘、网络独立弹窗高度与布局，移除监控内容滚动条；不改变 280pt 宽度、Toolbox 或日历弹窗。
- 保留当前未提交的 T037/T038 相关 UI 改动，不覆盖其他 dirty 文件。

## Acceptance Criteria

- 定位授权为 `.authorizedWhenInUse` 或 `.authorizedAlways` 后都会读取 Wi-Fi；拒绝/受限仍明确显示不可用。
- Apple Silicon GPU 显示“集成”、真实 `gpu-core-count`，且驱动可用时状态不再错误显示“已关闭”。
- `vm.swapusage` 全零时 Swap 显示“未使用”；非零时继续显示已用/总量。
- 当前启动卷可通过 `diskutil info -plist` 的 `SMARTStatus` 显示健康状态；命令失败时安全降级到现有 IOKit/“不可用”。
- 五类独立监控弹窗完整内容无滚动条、底部工具入口可见，宽度保持 280pt；屏幕高度不足时不越出可见区域。
- 相关测试、FewerCore 测试与 Fewer Debug 构建通过；签名实机完成五类弹窗与 Wi-Fi 权限交互核对，无法执行项明确记录。

## Evidence

- 2026-09-01：问题定位：Wi-Fi 授权回调只接受 `.authorizedAlways`，会把 macOS 常见的 `.authorizedWhenInUse` 错判为未授权；Apple Silicon IOKit 使用顶层 `gpu-core-count`，当前实现只查 `PerformanceStatistics` 的 `core count`，且类型/状态缺少 Apple AGX 与电源状态判定；本机 `sysctl vm.swapusage` 与 swapfile 均确认当前真实值为 0，用户选择显示“未使用”；启动卷 `diskutil info /` 返回 `SMART Status: Verified`，而当前父链属性只有 `NVMe SMART Capable`；监控弹窗固定高度配合 `ScrollView` 产生滚动条。
- 2026-09-01：Wi-Fi 授权回调现同时接受 `.authorizedWhenInUse`/`.authorizedAlways`；GPU 读取 `model`、`gpu-core-count`、`GPUConfigurationVariable.num_cores`、`CommandSubmissionEnabled` 与 `IOPowerManagement.CurrentPowerState`，Apple/AGX 判定为集成 GPU；Swap 全零显示“未使用”；SMART 在后台以 `/usr/sbin/diskutil info -plist /` 的 `SMARTStatus` 补充 IOKit 健康度。
- 2026-09-01：监控内容移除 `ScrollView`，保持 280pt 宽度并将 CPU/内存/GPU/网络/磁盘目标高度调整为 680/600/500/680/850pt，`showPopover` 继续按屏幕可见高度收敛。签名运行中 CPU、内存、磁盘、网络弹窗外层尺寸分别为 306×706、306×626、306×876、306×706，底部入口可见。
