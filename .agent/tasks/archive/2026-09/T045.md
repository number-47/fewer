# T045: Apple Translation 集成与目标语言切换

## Metadata

- Priority: P0
- Status: DONE
- Dependencies: T044

## Goal

在 macOS 15 及更高版本中通过系统 Translation API 自动翻译 OCR 原文，并允许仅重翻译目标语言。

## Scope

- 新增受 `#if canImport(Translation)` 和 `@available(macOS 15.0, *)` 保护的 Translation host，并修改 OCR coordinator/结果视图接入 source/target 语言和 generation；新增 App Swift 源后运行 `xcodegen generate` 并仅纳入对应工程生成物。
- 使用系统 `LanguageAvailability`、`TranslationSession` 和受 generation 保护的 coordinator；不引入任何外部翻译服务或自维护语言清单。
- macOS 14 保留 OCR 原文并显示明确的系统版本不可用状态。

## Acceptance Criteria

- 自动目标语言规则为中文到英语、其他语言到简体中文。
- 已安装语言可自动译文；需准备语言时显示真实准备状态；不支持、下载失败和检测失败状态明确可见。
- 目标语言列表来自系统支持语言；切换时不重新截图/OCR，只取消旧翻译并请求新语言。
- macOS 14 能安全编译和运行，不链接或调用未受保护的 Translation API。

## Validation

- 默认目标、状态/取消/generation 的 XCTest。
- FewerCore 测试、Fewer Debug 无签名构建、`git diff --check`。
- macOS 15/14 签名 Debug 与语言资源实测由 T046 在截图模块入口和全部错误状态接通后统一执行；不得将本任务编译成功表述为这些运行时验收。
