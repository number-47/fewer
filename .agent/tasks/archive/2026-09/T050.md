# T050: AI 翻译配置、密钥存储与兼容请求客户端

## Metadata
- Priority: P0
- Status: DONE
- Dependencies: T046

## Goal
提供不含截图数据的 OpenAI-compatible 文本翻译配置、Keychain 密钥存储和可测试的非流式 Chat Completions 客户端。

## Scope
- 新增 FewerCore 的 AI 配置校验、请求构造、响应解析和注入式传输边界及其 XCTest。
- 新增 FewerApp 的 UserDefaults 配置/Keychain 密钥存储和 AI 请求服务；只允许 HTTPS 或 loopback HTTP。
- 不修改 OCR 会话、翻译浮窗、Apple Translation、截图菜单或快捷键。

## Acceptance Criteria
- 远程端点必须 HTTPS 并具备密钥；仅 localhost、127.0.0.1、::1 可用 HTTP 且可省略密钥。
- 地址、模型存 UserDefaults，密钥仅存 Keychain；请求使用 ephemeral、无缓存、无 Cookie 的 URLSession，30 秒超时。
- 仅发送文本、源/目标语言、模型和翻译指令；不记录或持久化 OCR 文本、译文、响应正文和密钥。
- 固定解析 choices[0].message.content，并将鉴权、限流、超时、网络、服务端和无效响应映射为明确错误。

## Validation
- 新增核心 XCTest 覆盖配置、请求、解析与错误映射。
- FewerCore 测试、无签名 Fewer Debug 构建、git diff --check。
