# T046: 截图模块入口、硬化与端到端验收

## Metadata

- Priority: P0
- Status: DONE
- Dependencies: T045

## Goal

将截图翻译接入现有截图菜单，并完成隐私、取消、多显示器、Retina 和普通截图回归验收。

## Scope

- 修改 `ModuleHost` 的截图命令声明与路由、必要的 `ScreenshotService`/截图核心保护与测试；若新增源文件才运行 `xcodegen generate` 并仅纳入对应工程生成物。
- 覆盖多屏/Retina 原始图像、不超 20MP 的大图保护、窗口边缘 clamp、错误状态和普通截图回归。
- 不修改现有发布/XPC/Finder 工作，不写 OCR/译文到持久化介质，不添加菜单栏一级 OCR 模块或第二套命令路由。

## Acceptance Criteria

- 快捷键与“智能截图 → 截图翻译”菜单均进入同一流程。
- 连续触发只显示最新请求，普通截图仍进入 Markup Editor，OCR 流程绝不进入编辑器。
- 主/副屏、Retina/非 Retina 选区使用真实 CGImage 像素且浮窗不出界。
- OCR 和译文内容未写入日志、UserDefaults、App Group、文件或网络请求。

## Validation

- 相关 XCTest、`xcodegen generate` 后工程漂移检查、FewerCore 测试、Fewer Debug 无签名构建、`git diff --check`。
- `./script/verify.sh`。
- macOS 15 签名 Debug 端到端与多显示器矩阵由 T047 记录；不得以本任务无签名构建或 `verify.sh` 替代运行时验收。
