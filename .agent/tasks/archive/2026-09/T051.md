# T051: 截图翻译浮窗的系统与 AI 来源切换

## Metadata
- Priority: P0
- Status: DONE
- Dependencies: T050

## Goal
保持 Apple Translation 默认行为，并在 OCR 结果浮窗中提供显式 AI 切换、配置入口、取消和重试。

## Scope
- 修改 OCR 翻译会话、协调器、结果浮窗和截屏设置页；接入 T050 的配置和客户端。
- 新截图始终默认系统翻译；AI 仅在用户切换后请求 OCR 文本。
- 不改变普通截图、Vision OCR、快捷键、菜单路由或发布/XPC/Finder 边界。

## Acceptance Criteria
- 结果浮窗可在系统/AI 间切换；切换来源或目标语言取消旧请求，过期响应不得回写。
- 未配置 AI 时显示设置入口；失败显示重试和切回系统，不自动回退。
- AI 可在源语言未知时使用自动检测；目标语言继续复用系统列表。
- 设置页提供端点、模型、密钥、保存并测试、清除配置和联网文本披露。

## Validation
- 扩展状态与回归 XCTest；FewerCore 测试、无签名 Fewer Debug 构建、git diff --check。

## Evidence
2026-09-03：OCR 会话新增 provider 状态；每次 `beginRecognition()` 重置为 system。结果浮窗新增系统/AI 切换，AI 仅在切换后读取已验证配置并请求文本；未知源语言在 AI 路径使用 auto。未配置显示设置入口；失败可重试或切回系统；设置页新增完整 endpoint、模型、Keychain 密钥、保存并测试、确认清除与联网文本披露。

2026-09-03：切换翻译源、目标语言、重试、窗口关闭和新截图均取消活动 AI Task；OCR 会话 generation 继续丢弃所有过期回写。主对话审查发现并修复目标语言切换只丢弃响应、未取消旧请求的问题。

主对话验收：仅修改授权的 OCR 会话、协调器、浮窗、设置与对应测试/工程生成物；普通截图、OCR、快捷键和菜单路由未改。`xcodegen generate` 成功，FewerCore 400 tests 通过，无签名 Fewer Debug 构建通过，`git diff --check` 通过。真实浮窗和兼容服务交互移交 T052。
