# T013: PR1 — CI 基线与临时文件清理

## 元信息

- 优先级：P0
- 状态：BACKLOG
- 推荐执行器：implementer
- 依赖：T020

## Goal

在其余架构改动前建立可重复的 GitHub Actions 门禁，并移除已跟踪的临时调试文件。此 PR 不改变应用运行时、签名方式或 Helper 嵌入方式。

## Context

- 仓库没有 `.github/workflows`。
- `script/verify.sh` 已定义本地配置、模板、单测、完整 Debug 构建、产物和工作树检查，但会写本地验证 receipt，不应原样当作 CI 黑盒。
- `FewerCore/Models/InputEnhancementSettings.swift.tmp` 是已跟踪的 shell 调试残留；`.gitignore` 未覆盖常见编辑器临时文件。
- `FewerUITests` 已存在，但运行依赖 GUI 会话和权限，不应伪装成无签名 CI 门禁。

## Scope

- 新增 `.github/workflows/ci.yml`。
- 删除 `FewerCore/Models/InputEnhancementSettings.swift.tmp`。
- `.gitignore` 增加 `*.tmp`、`*.swp`、`*.bak`。
- 如需避免 workflow 重复命令，可新增只读的 `script/ci_verify.sh`；不得修改 `script/verify.sh` 的本地 receipt 语义。

## Implementation steps

1. 使用固定的 macOS runner/Xcode 版本，安装或校验 `xcodegen`、`xcbeautify`。
2. 运行 `xcodegen generate`，随后用 `git diff --exit-code -- Fewer.xcodeproj` 检查工程漂移。
3. 使用仓库约定的 `.build/DerivedData`、`SYMROOT`、`OBJROOT` 运行 `FewerCore` 单测和 `Fewer` 无签名 Debug 构建。
4. 校验模板以及 App、Finder Extension、Shortcut Helper 三个产物存在。
5. 清理已跟踪 `.tmp` 并补 ignore。

## Acceptance criteria

- [ ] workflow 在 pull_request 和主分支 push 上触发，权限保持只读最小化。
- [ ] CI 使用明确的 Xcode/macOS 环境，命令不依赖本机绝对路径或证书。
- [ ] `xcodegen generate` 后工程无漂移；核心单测、完整 Debug 构建、模板和三产物检查均为硬门禁。
- [ ] UI Tests 明确标注为签名/GUI 后续验收，不以“可选且失败不阻断”冒充门禁。
- [ ] `.tmp` 已删除，常见临时后缀被忽略。
- [ ] 未改 `ENABLE_USER_SCRIPT_SANDBOXING`、Helper 嵌入或生产代码。

## Validation

```bash
xcodegen generate
git diff --exit-code -- Fewer.xcodeproj
xcodebuild -project Fewer.xcodeproj -scheme FewerCore -configuration Debug \
  -derivedDataPath .build/DerivedData \
  SYMROOT="$PWD/.build/DerivedData/Build/Products" \
  OBJROOT="$PWD/.build/DerivedData/Build/Intermediates.noindex" \
  CODE_SIGNING_ALLOWED=NO test | xcbeautify
xcodebuild -project Fewer.xcodeproj -scheme Fewer -configuration Debug \
  -derivedDataPath .build/DerivedData \
  SYMROOT="$PWD/.build/DerivedData/Build/Products" \
  OBJROOT="$PWD/.build/DerivedData/Build/Intermediates.noindex" \
  CODE_SIGNING_ALLOWED=NO build | xcbeautify
./script/verify_templates.sh
```

## Exclusions

- UI Tests、签名、公证、DMG。
- 构建脚本沙盒化和 Helper 嵌入重构。
