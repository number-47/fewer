# T011: 鼠标手势右键分界

## 元信息

- 优先级：P1
- 状态：CANCELLED
- 推荐执行器：implementer
- 依赖：无
- 替代任务：T021

## 原 Goal

对配置了右键手势的按钮，移动不超过 4pt 时保持普通右键；一旦移动超过 4pt，即使尚未识别方向也不得再回放右键。

## 原范围与要求

- `FewerCore/Services/InputProcessing.swift`
- `FewerCoreTests/InputProcessingTests.swift`
- `FewerShortcutHelper/EventTapController.swift`
- 在纯 Core 层定义可测试的 4pt 判定及 completion 输入，覆盖边界值。
- `GestureSession` 保存已超过点击容差的不可逆状态。
- completion 仅在未越过容差且未匹配规则时回放点击。

## 原 Completion Report

- 新增 `MouseGestureClickTolerance`，以实际欧氏距离判定是否超过 4pt。
- 手势会话一旦超过容差即不可逆；松开、Escape、超时及重置仅在未越界时回放右键。
- 新增 0pt、恰好 4pt、超过 4pt、斜向移动和 completion 回归测试。
- 当时验证：FewerCore 256 tests passed；FewerShortcutHelper Debug build succeeded；`git diff --check` passed。

## 取消原因

用户在签名实机报告普通右键仍会消失、手势会弹出右键菜单并存在误识别。代码复核确认 4pt 点击容差与 16pt 最小识别段形成 5–15pt 的吞点击区间；现有 completion 单元测试没有覆盖真实 down/drag/up、超时回放后残余物理 `mouseUp`、应用切换和 Chrome/Finder 行为。继续微调 T011 不足以修复，需要由 T021 重做完整事件状态机并进行真实应用验收。
