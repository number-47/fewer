# T007: 磁盘模块

## 元信息

- 优先级：P1
- 状态：DONE
- 推荐执行器：implementer
- 依赖：T003

## Goal

实现 Stats 风格磁盘容量、读写、卷信息和 SMART 降级显示，接入状态项及弹窗。

## 范围

- `FewerApp/Services/SystemMetricsService.swift`
- `FewerApp/Views/DashboardModuleView.swift`
- `FewerApp/App/FewerApp.swift`
- 确有必要的新 FewerApp 磁盘服务/视图文件。

## 要求

- 发布可空磁盘快照：卷名、总量、可用/已用、文件系统、连接类型、累计和实时读写、历史。
- 真实吞吐使用差值计数器；首次、卷切换、倒退和读取失败不伪造速率。
- SMART 温度、健康度、寿命、警告、通电时间等通过可失败 IOKit 路径读取；不支持、外置盘或无权限均显示“不可用”。
- 状态项支持百分比、容量、读写速率、吞吐图和文本；弹窗显示卷与 SMART 详情。
- 不修改 CPU/GPU/内存/网络字段含义、Core、ShortcutHelper、project.yml 或 .agent。

## 验证

- Fewer Debug build、Core tests 与 diff check。

## Completion Report

- 添加可空 DiskSnapshot/DiskSMARTSnapshot：启动卷容量、卷信息、累计/实时 IOKit 读写与 SMART 降级。
- 状态项和弹窗接入容量、吞吐历史、卷详情和 SMART；当前机器无 SMART 字段时显示不可用。
- 验证：完整 verify.sh、Debug build、258 Core tests、diff check passed；Debug Fewer 进程可启动。
