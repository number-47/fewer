# T037: 菜单栏监控独立弹窗精修

## Metadata

- Priority: P1
- Status: DONE
- Dependencies: 无

## Goal

依据参考图统一 CPU、GPU、内存、磁盘和网络五个菜单栏独立弹窗，在 280pt 固定宽度内提供紧凑、可滚动且使用真实采样数据的卡片式详情。

## Scope

- 精修监控弹窗容器、五类详情布局、趋势图和底部工具入口。
- 复用现有 `SystemMetricsService` 数据与可见性采样，不增加新的特权读取、常驻进程或虚构硬件数据。
- 保留菜单栏模块顺序、Toolbox 信息架构、监控偏好和设置入口；不顺手重构采样器。

## Acceptance Criteria

- 五个独立弹窗固定宽度 280pt，内容高度不超过 560pt，超出内容可滚动；内边距、卡片圆角和卡片间距与参考图的 16/12/12pt 规范一致。
- CPU、GPU、内存、磁盘、网络均按参考图形成分组卡片，展示现有真实快照与 60 秒历史；数据缺失时明确显示“不可用”。
- CPU、GPU、内存底部可打开活动监视器，磁盘可打开磁盘工具，网络可打开活动监视器的网络视图或系统可用的等效入口。
- 弹窗出现时沿用 1 秒可见模块刷新节奏，关闭后停止该模块的可见性采样请求。
- 相关测试和 Fewer Debug 构建通过；五个菜单栏入口的真实弹窗完成截图或人工交互核对，未执行部分必须明确记录。
