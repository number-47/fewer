## 关键决策

- GPU 默认启用并预置迷你百分比，但首次安装和升级均不自动显示菜单栏状态项。
- SMC、IOReport、SMART 与 Wi-Fi 定位失败一律降级为“不可用”，不伪造 0。
- CPU 不注册菜单栏快捷操作；工具箱及系统模块命令保持不变。
