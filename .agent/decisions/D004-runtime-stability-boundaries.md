# D004: 先恢复输入完整性，再推进 Finder 与性能收口

- 日期：2026-08-24
- 状态：accepted
- 背景：用户实机报告普通右键丢失、手势弹出右键菜单、误识别、Finder 菜单不可见、权限入口缺失以及日历/设置卡顿。代码核对确认这些不是一个根因：输入事件存在 4pt/16pt 死区和取消后的残余序列；设置主线程轮询 `pluginkit`；日历按行同步查询 EventKit；当前权限按钮没有出现在实际诊断 tab。
- 决策：先执行无代码的真实运行基线 T020；输入层以“一段物理按键序列只有一个终态”为硬约束，T011 取消并由 T021 替代；权限中心准确区分主 App、Helper、Finder Extension；Finder 菜单在系统原生右键恢复后单独诊断；高频 UI 更新不得同步启动进程、读写文件或查询 EventKit。
- 影响：新增 T020-T026，并将其加入 T012 发布依赖。稳定性 P0 完成前不执行会扩大输入/Finder 改动面的 T015/T016；所有修复必须有真实 Chrome/Finder/Safari 或签名 UI 性能证据，构建通过不等于验收。
